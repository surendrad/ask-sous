Brand colour is locked (Warm Ember). Three font pairings, shown against the actual palette with a live type scale and a realistic content block — an insights answer with stats, the kind of thing the chat UI renders constantly.

Option A — Inter, all business

Single-family: Inter for everything, JetBrains Mono for numbers/citations. Neutral, extremely legible at small sizes, zero personality risk. The safest choice for a data-dense chat UI.

Option B — Fraunces display + Inter UI

Fraunces is a warm, characterful serif with soft, organic curves — used only for display/headings, giving the product a hospitality feel without sacrificing legibility, since all dense UI text (chat, labels, data) stays in Inter.

Option C — Manrope, all business
