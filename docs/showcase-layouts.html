Ask Sous — Layout Showcase

Layout Approach

The one real structural fork: should the campaigns panel live alongside chat (split view — you watch a draft update live while still able to keep asking questions) or as its own full-screen destination you navigate to (simpler, more spacious, one thing at a time). Both use the same sidebar + restaurant switcher.

Option A — Split view

Chat and the campaigns panel are visible side by side. Good demo value — you can literally watch the panel populate as the agent drafts copy without switching screens. Costs horizontal space; campaigns panel is narrow.

Option B — Separate full-screen views

Chat, Campaigns, and Dashboard are each a full-width destination reached via the sidebar. More breathing room per view, simpler mental model, easier to extend later.

View Mockups — Full Detail

Toggle between the two approaches to see the chat view at full size. Realistic content: Golden Wok, mid-conversation about a slow Tuesday, a campaign drafted in response.

Dashboard View

Nice-to-have per the master plan — 2–3 pre-computed charts for visual demo value, not core to the agent story. Reached via the sidebar in both layout approaches.

Mobile Layout

Sidebar collapses to a bottom tab bar. On mobile, the split-view approach isn't viable at any width, so both options converge on single-screen views below the tablet breakpoint (~768px) — one less thing to design twice.
